자주 묻는 질문

예약은 꼭 전화로만 해야 하나요?

현재는 전화 예약을 기본으로 운영합니다. 방문 위치와 시간, 배정을 실시간으로 확인해야 해서 전화가 가장 빠르고 정확합니다. 문자 예약도 가능하니 편한 방식으로 연락 주세요.

예약 내용을 다시 확인하고 싶어요.

예약 전화번호로 연락 주시면 예약자 확인 후 일정과 코스, 총비용을 다시 안내해 드립니다.

추가 이동비는 어떻게 정해지나요?

과천시 안에서도 위치에 따라 차량 이동 기준이 달라집니다. 예약 시 방문 주소를 기준으로 발생 여부와 금액을 미리 안내해 드리며, 방문 후 추가되는 비용은 없습니다.

불편 사항은 어디로 말하면 되나요?

같은 번호로 연락 주시면 됩니다. 관리 품질, 시간 약속, 비용 안내와 다른 점 등 어떤 내용이든 확인 후 답변드립니다.

사이트 내용과 전화 안내가 다르면 어느 쪽이 맞나요?

최신 기준은 전화 안내입니다. 사이트 반영이 늦은 부분을 발견하셨다면 알려주시면 바로 수정하겠습니다.

분실물이 생기면 어떻게 하나요?

방문형 관리 특성상 분실물은 드물지만, 관리 후 물건이 보이지 않으면 바로 연락 주세요. 방문 이력 기준으로 즉시 확인해 드립니다.

전화했는데 연결이 안 돼요.

상담이 몰리는 시간대에는 연결이 늦어질 수 있습니다. 문자를 남겨주시면 확인 즉시 회신드리며, 방문 위치와 희망 시간을 함께 남겨 주시면 더 빠르게 안내받으실 수 있습니다.

예약 확정 내용은 어떻게 확인하나요?

예약이 확정되면 일시, 코스, 추가 이동비를 포함한 총비용을 안내해 드립니다. 안내 내용과 다른 부분이 있으면 진행 전에 바로 말씀해 주세요.

대신 예약하고 다른 분이 받게 하려는데 가능한가요?

가능합니다. 받는 분의 연락처와 방문 시간에 현관을 열어주실 수 있는지만 확인해 주시면 됩니다. 부모님이나 가족 선물로 예약하시는 경우에도 같은 방식으로 진행됩니다.
